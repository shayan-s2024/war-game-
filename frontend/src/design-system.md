# WW3 Cinematic Command Center — Design System

Direction: cinematic command center / information-dense strategy interface.

- Visual language: deep-space surface, layered glass, precision HUDs, spherical 3D focus objects, restrained cyan + gold + danger accents.
- Motion: short UI transitions, slow orbital motion, breathing highlights, focus flights, and hover lift; no perpetual high-energy movement that makes the dashboard noisy.
- Depth: every major panel uses a three-level elevation model; the globe is the hero object and receives the strongest rim light, atmosphere, and orbital accents.
- Layout: preserve the existing game information architecture; improve hierarchy through depth, grouping, and whitespace rather than adding decorative sections.
- Accessibility: all major animations respect prefers-reduced-motion; interaction states remain available without animation.
