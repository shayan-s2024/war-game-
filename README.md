# جنگ جهانی (War Game)

بازی استراتژیک چندبخشی با رابط وب، API مبتنی بر Django و ربات تلگرام.

## ساختار پروژه

- `frontend/` رابط React و TypeScript، شامل صفحهٔ «کشور من» و نقشهٔ دوبعدی
- `backend/` API، منطق بازی، داده‌ها و مدل‌های Django
- `telegram_bot/` ربات تلگرام و ماژول‌های بازی
- `nginx/` پیکربندی پراکسی
- `docker-compose.yml` اجرای سرویس‌ها با Docker
- `run_frontend.bat` راه‌انداز توسعهٔ محلی در ویندوز

## اجرای توسعهٔ محلی در ویندوز

1. فایل `.env.example` را به `.env` کپی و مقادیر لازم را تنظیم کنید. کلیدهای واقعی را به مخزن اضافه نکنید.
2. `run_frontend.bat` را اجرا کنید. فرانت‌اند روی `http://localhost:5173` بالا می‌آید و API روی `http://127.0.0.1:8000`.

برای اجرای دستی، وابستگی‌های `backend/requirements-local.txt` را در محیط مجازی پایتون نصب کنید؛ سپس در `backend/` مهاجرت‌ها و seed را اجرا و Daphne را راه‌اندازی کنید. در `frontend/` دستور `npm ci` و سپس `npm run dev` را اجرا کنید.

## امنیت

فایل‌های `.env`، دیتابیس‌های محلی، لاگ‌ها، محیط‌های مجازی و `node_modules` در مخزن قرار نمی‌گیرند. `.env.example` فقط مقادیر نمونه دارد.
